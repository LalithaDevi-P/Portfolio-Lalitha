🚀 Getting Started

Prerequisites

Make sure you have the following installed:

Node.js

npm

Git

Check your installation:

node -v
npm -v
git --version

Clone the Repository

git clone https://github.com/LalithaDevi-P/Portfolio-Lalitha.git

Navigate to the Project

cd Portfolio-Lalitha

Install Dependencies

npm install

Start the Development Server

npm run dev

Open the URL shown in the terminal, usually:

http://localhost:5173

🏗️ Build for Production

Create an optimized production build:

npm run build

The generated production files will be available inside:

dist/

👀 Preview the Production Build

To preview the production build locally:

npm run preview

Vite will display the local preview URL in the terminal.

🔍 Run ESLint

To check the project for linting issues:

npm run lint
