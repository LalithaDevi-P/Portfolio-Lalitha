# 🚀 My Portfolio — Lalitha Devi

A modern, responsive personal portfolio website built with **React and Vite** to showcase my skills, projects, certifications, achievements, and professional journey.

The portfolio is designed to provide recruiters and developers with a quick overview of my technical background and the projects I have built.

🚀 Getting Started
Prerequisites

Make sure you have installed:

Node.js
npm
Git

Check your installation:

node -v
npm -v
git --version
Clone the Repository
git clone https://github.com/LalithaDevi-P/Portfolio-Lalitha.git
Navigate to the Project
cd Portfolio-Lalitha
Install Dependencies
npm install
Start the Development Server
npm run dev

Open the URL shown in the terminal, usually:

http://localhost:5173
